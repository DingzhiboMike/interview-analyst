# interview-analyst

Скилл для Claude.

Аналитик пользовательских интервью. Берёт сырой транскрипт и выдаёт структурированный разбор: квалификация респондента, резюме, ключевые выводы с маркерами силы сигнала, открытые вопросы и конкретные следующие шаги.

## Когда использовать

- Разобрать транскрипт custdev-интервью
- Вытащить сигналы для продукта и маркетинга
- Понять, что на самом деле сказал респондент

Не подходит для обобщений по одному интервью и SWOT/персон-плакатов.

## Установка

**Claude Code.** Склонируйте репозиторий в папку скиллов:

```bash
git clone https://github.com/DingzhiboMike/interview-analyst.git ~/.claude/skills/interview-analyst
```

**Claude.ai / десктоп-приложение.** Скачайте репозиторий как ZIP (Code → Download ZIP) и загрузите его в настройках Claude, в разделе со скиллами.

После установки скилл включается сам, когда запрос подходит под его описание. Можно вызвать и явно — по имени `interview-analyst`.
